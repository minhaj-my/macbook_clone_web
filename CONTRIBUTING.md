# Contributing to Macbook Landing Clone

First off, thank you for considering contributing to this project! Any contribution you make will be greatly appreciated.

## Where do I start?

If you have an idea for a new feature or have found a bug, please open an issue first to discuss it. This allows us to coordinate our efforts and avoid duplicated work.

## How to Contribute

1.  **Fork the repository:** Click the "Fork" button at the top right of this page.
2.  **Clone your fork:** `git clone https://github.com/your-username/macbook-landing-clone.git`
3.  **Create a new branch:** `git checkout -b my-awesome-feature`
4.  **Make your changes:** Make your changes to the code.
5.  **Commit your changes:** `git commit -m "Add some awesome feature"`
6.  **Push to your fork:** `git push origin my-awesome-feature`
7.  **Create a pull request:** Open a pull request from your fork to the main repository.

## Style Guide

Please try to follow the existing coding style. This project uses Prettier and ESLint to enforce a consistent style. Before committing your changes, please run `npm run lint` to make sure your code conforms to the style guide.
